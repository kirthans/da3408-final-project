A small field guide

From a game to an estimate.

What is a PGN?

Portable Game Notation is a plain-text record of a chess game. It includes moves such as “1. e4 e5” and may include player names, ratings, clocks and event details. A single file can contain several games.

Get your game

On Lichess, open a finished game and its analysis board, then look below the board for the PGN download or export option. Export with clocks if available. On Chess.com, open a finished game and use Share or Download to copy its PGN or download the PGN file. Menu labels can vary by device.

Make an estimate

Paste the text or choose a .pgn file (up to 1 MB), then select Read game. If the file contains several games, choose one. For a game without a recorded time control, select Classical, Rapid or Blitz. Choose Estimate ratings; analysis may take a little time. Cancel stops your browser waiting for the result.

Read the ratings

The large numbers estimate each player’s Lichess-equivalent rating for the selected time control. The green bar shows an 80% uncertainty interval on a shared 600–3200 scale. Across comparable games, about 8 in 10 intervals should contain the player’s rating. A dashed blue marker shows a rating included in the file; those ratings are not used by the model.

Explore the moves

Use the board’s arrow buttons, focus it and press your keyboard arrows, or click a move. Symbols identify inaccuracies (?!), mistakes (?) and blunders (??), alongside colour. Click an influential move to see its position. Its Elo change describes how that move affected the estimate, not a change to anyone’s official rating.

Know the limits

One game can be unrepresentative. An opening you know, a distraction, an unusual opponent or a short game can change the estimate. Over-the-board and other websites’ ratings use different scales. Bullet and correspondence games are unsupported. This tool cannot determine cheating or measure someone’s potential.

Privacy and demo data

Games are sent to the analysis service when you read or estimate them. Games are not stored. PGNs can include personal names; remove details you do not want to send. The clearly labelled Demo data mode uses a bundled illustrative result and does not call the API.

The Pipeline tab

The current model card shows the model version and its average rating error in Elo points (MAE; lower is better). The replay card shows which month is being revealed, whether the replay is playing or paused, and the wait until the next month. It compares the current and previous models with the reference error. Coverage tells you how often the intervals contain the recorded ratings.

The training diagram shows the steps from data to a model; repeated monthly steps are grouped together. Choose a run to colour its steps by outcome. Reused steps need no new work. The history lists training decisions: promoted means the new model passed the checks, rejected means it did not, and no change means existing work was reused. Expand Details for timing, games processed per second and any error. Links open experiment records and monitoring charts.

Administrators can request a manual retrain with a reason and API key. It uses the months revealed so far. The key is cleared after submission and is never saved by this page.

Why the model retrains

People and playing habits change. Drift means new games look different from the games the model learned from, or its errors grow. This demo reveals 2020 one month at a time, as if those games were arriving today. When the average error grows enough, an alert requests training with the available months. A new model replaces the current one only if its error improves and its uncertainty intervals meet the checks. A “drift injection ON (demo)” badge means an artificial change is enabled for demonstration.

What the numbers can’t tell you

The scale is Lichess-equivalent, not a FIDE or over-the-board rating. Games played over the board often have no clock information, so the estimate has less evidence about how time was used. One game is a small sample of a player’s strength. An 80% interval is not a certainty: even well-calibrated intervals miss about 2 in 10 comparable ratings.

Privacy

Games are not stored. Uploaded ratings are display-only: they help you compare the estimate with the file but never influence the prediction.
